# Built-in dynamic sticker pack

The keyboard's built-in dynamic sticker templates and the art they draw from
are generated by the scripts here. Run both after changing either:

```bash
python3 tools/dynstickers/svg_to_lottie_shapes.py
```

```bash
python3 tools/dynstickers/build_builtin.py
```

| Script | Writes |
|---|---|
| `svg_to_lottie_shapes.py` | `app/src/main/assets/dynstickers/art/art.json`, the art library |
| `build_builtin.py` | `app/src/main/assets/dynstickers/builtin/pack.json` and `scenes/*.json` |
| `preview_art.py OUT --sheet [--compare]` | SVGs of the art library and a contact sheet, Noto originals alongside with `--compare` |

## Art

`svg_to_lottie_shapes.py` converts two sources into Lottie shape groups:

- Noto Emoji's colour SVGs (googlefonts/noto-emoji, `2D/svg/`, Apache-2.0),
  fetched at the commit pinned in the script into `.cache/`, which git ignores.
  The `NOTO` table picks which drawings, under which ids.
- Our own drawings in `custom_art.py`, written as SVG. These are the things to
  write on (a ribbon, a wooden sign, a calendar page, a mug), certificate
  parts, doodles, comic bursts, and the pieces post and quote cards use.

Transforms are baked into the points, and linear gradients convert exactly.
Radial gradients are exact under rotation and scale and become the nearest
circle otherwise. Clip paths are intersected with shapely
(`pip install shapely`). Masks, filters and blend modes are dropped with a
warning: 13 Noto faces use multiply for their blush, which is drawn as normal.
Each drawing is cropped to what it draws. `x0`/`y0` record where the crop
starts, so a template can put words on part of a drawing.

## Templates

`build_builtin.py` writes every template as a `DynScene`, using the Kotlin
serial names and leaving out anything at its default. Templates are built
from a few dozen compositions ("archetypes") drawn with different words,
palettes, art and motion. The phrase table in `build_phrases()` lists English
phrases, Bengali in Bengali script and Bengali typed in Latin letters, and
concept tags from `EmojiConcepts`' vocabulary. A phrase that the template's
own lines cannot take is dropped with a note.

The manifest carries each template's slots, worked out the way
`SceneToLottie.compile` works them out. `BuiltinPackTest` in `:core:content`
compiles every scene through the real `DynStickerStore`, checks the slots
match, that every drawing a scene names exists, that every phrase fits its
template, and that common messages find several templates.

Fonts: `DynaPuff-Bold` and `DynaPuff` for stickers, `Anton` for impact-style
memes, and the platform's `sans-serif*` and `serif` families for cards.

Loops close on themselves: every looping motion's length divides the scene's,
and spins turn a whole number of the shape's points per loop. A loop's phase
is shifted by giving it a negative `delay`.
