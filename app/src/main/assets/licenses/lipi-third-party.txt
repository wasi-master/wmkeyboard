Third-party code in the Indic script converter
==============================================

Convert script and Sanskrit's Write in another script run in a native
library (libwmlipi.so, built from native/lipi-jni) on vidyut-lipi, Arun
Prasad's transliterator for the Ambuda project
(https://github.com/ambuda-org/vidyut), released under the MIT licence
below, and the Rust crates listed after it. vidyut-lipi declares MIT in its
Cargo metadata and its repository's README and ships no licence file of its
own, so the standard MIT text is given here with its author's name.

Each other crate remains under its own licence; the SPDX licence expression
from its Cargo metadata is listed beside it. "A OR B" means the crate is
offered under either licence at the user's option; this app receives every
crate under the permissive option of its expression. The proc-macro crates
(clap_derive, heck, proc-macro2, quote, syn, thiserror-impl, the
wasm-bindgen macros) run while the library is built and are not part of it.
The licence texts accompany each crate's source at
https://crates.io/crates/<name>. The Apache-2.0 text is bundled in this app
(apache-2.0.txt).
