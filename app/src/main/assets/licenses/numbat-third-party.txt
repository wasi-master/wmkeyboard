Third-party Rust crates in the Numbat calculator library
========================================================

Sums with units in the calculator ship as a native library (libwmnumbat.so)
built from David Peter's Numbat (numbat 1.24.0, MIT OR Apache-2.0) and the
Rust crates listed below, with plotting and exchange-rate fetching left out.
Each crate remains under its own licence; the SPDX licence expression from
its crates.io metadata is listed beside it. "A OR B" (or "A/B") means the
crate is offered under either licence at the user's option; this app
receives every crate under the permissive option of its expression.

The licence texts involved (Apache-2.0, MIT, BSD-2-Clause, BSL-1.0,
Unlicense, Unicode-3.0, MPL-2.0) accompany each crate's source, available at
https://crates.io/crates/<name>. The Apache-2.0 text is also bundled in this
app (apache-2.0.txt; the MIT text appears in the other mit-*.txt notices).

The one MPL-2.0 crate (option-ext) is included unmodified; its complete
source code is available from crates.io at the address above, which
satisfies MPL-2.0 section 3.2.

This is the set of crates the Android library is built from, procedural
macros included (they run at build time and leave no code of their own).
