jquery.ime input methods
https://github.com/wikimedia/jquery.ime

The transliteration schemes under assets/input_methods/jquery/ are rule
files from Wikimedia's jquery.ime (commit 77ed339ee9ce, 2026-10-20), shipped
unchanged, and two from Indic Keyboard's copy of it (android-ime, commit
311d331bb274, 2026-09-09; https://gitlab.com/indicproject/android-ime). WM
Keyboard reads them with its own code (RegexRules.kt); no part of jquery.ime's
JavaScript is included.
