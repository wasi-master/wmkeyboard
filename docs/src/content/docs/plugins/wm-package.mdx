## The manifest

`plugin.json`, at the top of the archive.

```json title="plugin.json"
{
  "format": "wmkeyboard-plugin",
  "id": "com.example.weather",
  "name": "Weather",
  "pluginVersion": "1.0.0",
  "author": "Your Name",
  "description": "Today's forecast.",
  "apiVersion": 5,
  "permissions": ["network", "storage"],
  "hosts": ["api.open-meteo.com"],
  "tool": {"icon": "cloud", "tile": true, "float": true, "keyword": "weather", "chip": true},
  "settings": [
    {"key": "units", "type": "choice", "label": "Units", "default": "metric", "options": ["metric", "imperial"]}
  ]
}
```

| Field | Required | Meaning |
|---|---|---|
| `format` | yes | Always `"wmkeyboard-plugin"`. |
| `id` | yes | Unique. 3 to 64 characters of `a-z 0-9 . _ -`, starting with a letter or digit. Reverse domain by custom: `com.yourname.tool`. |
| `name` | yes | Shown everywhere. Up to 40 characters. |
| `pluginVersion` | yes | Your version, such as `"1.2.0"`. |
| `apiVersion` | yes | `5`. |
| `author`, `description` | no | Shown on the install screen. |
| `entry` | no | The script to run. `main.py` by default. |
| `permissions` | no | See [Permissions](/plugins/permissions/). |
| `hosts` | with `network` | Websites `http` may reach, up to 16. [More](/plugins/guides/internet-and-ai/#asking-for-the-internet). |
| `tool` | no | Where the plugin opens from: `icon` (a Material Symbols name or `"assets/icon.svg"`, [more](/plugins/guides/pages-and-timers/#your-icon)), `color` (`"#RRGGBB"`), `tile`, `float`, `keyword`, `chip`, `height`, `fullBleed`. [More](/plugins/guides/pages-and-timers/#where-a-plugin-opens-from). |
| `settings` | no | Rows on the plugin's settings page, up to 24. A `host` setting adds the server the user types to `hosts`. [More](/plugins/guides/saving-and-settings/#a-settings-page). |
| `actions` | with `selection` | Buttons over selected text, up to 16. [More](/plugins/guides/text-and-selection/#buttons-over-selected-text). |
| `providers` | no | Rows for the keyboard's provider lists, such as web search or translate, up to 8. [More](/plugins/guides/providers/). |
| `previews` | with `previews` | File types the plugin shows in the file manager, up to 16: `id`, `name`, `extensions`, `names`, `mimes`, `maxBytes`, `thumbnails`. [More](/plugins/guides/file-previews/). |
| `syntax` | no | Grammars that colour file types, up to 16: `id`, `name`, `extensions`, `names`, `grammar` (inline, or `"assets/name.json"`). [More](/plugins/guides/file-previews/#syntax-colours). |
| `panel` | no | `false` for a plugin made only of selection actions, providers, previews or grammars. |

A manifest the app does not fully understand, such as one with an unknown
permission, is refused at install rather than half-installed.

## The Python you get

A Python 3 interpreter built into the keyboard. It covers what everyday code
needs:

- functions with defaults, `*args`, `**kwargs` and keyword-only parameters,
  `lambda`, decorators
- `class` with one base or several (in Python's method order), `super()`,
  `@property`, `@staticmethod`, `@classmethod`, the usual `__dunder__`
  methods, metaclasses, and class keywords such as
  `class Tool(Plugin, name="ocr")` for `__init_subclass__`
- `if`, `for`, `while`, `try`/`except`/`finally`, `raise`, `with`, `assert`,
  `global`, `nonlocal`, `del`, and `match`/`case` with Python's patterns
- generators: `yield`, `yield from`, `send`, `throw` and `close`, and generator
  expressions, which run only as far as something asks
- the walrus `:=`, `...`, `eval`, `exec` and `compile`, `from module import *`,
  and `from __future__ import annotations`, which keeps annotations as their
  text
- `async def`, `await`, `async for` and `async with`, which `asyncio` runs one
  coroutine at a time (see below), and `async for` in a comprehension
- list, dict and set comprehensions, f-strings (`{x=}` too, and a field that
  runs over several lines of a triple-quoted f-string), slicing, slice
  assignment, and unpacking with a starred target (`first, *rest = items`)
- type annotations: a class's and a module's are evaluated into
  `__annotations__` where they stand, a function's the first time its
  `__annotations__` is read, and one naming something not defined yet is kept
  as its text
- your own exceptions: `class NotFound(Exception): pass`, and every builtin
  exception class Python has, `ExceptionGroup` and `BaseExceptionGroup`
  included, with `split`, `subgroup` and `add_note` (there is no `except*`)
- subclasses of `dict`, `list`, `str`, `int`, `float`, `tuple`, `set` and
  `bytes`, with `super()` reaching the type's methods and `__missing__` for a
  dict subclass, and of `property`, `classmethod` and `staticmethod`, whose
  instances work as the decorator does unless the class gives its own
  `__get__`
- integers of any size, as Python's are, with `<<`, `>>` and the other bit
  operators, and `int.from_bytes` and `n.to_bytes` for binary formats
- complex numbers: `1 + 2j`, `complex("1+2j")`, `z.real`, `z.imag`,
  `abs(z)`, and `cmath` for their square roots, logarithms and the rest
- Python's string escapes, `\x41`, `\u00e9`, `\U0001F600` and `\N{BULLET}`
  included
- Python's sorting (stable, with `key` and `reverse`), dict keys (`1` and
  `1.0` are one key; `__hash__` and `__eq__` decide for your classes),
  `frozenset`, `bytearray`, and `re.compile` with lookahead, lookbehind and
  backreferences
- `type(x)` answers with the type (`type(1) is int`), and `d.keys()`,
  `d.values()` and `d.items()` are live views of the dict, as in Python
- descriptors (`__get__`, `__set__`, `__set_name__`), `__getattribute__`, a
  live `obj.__dict__`, in-place methods such as `__iadd__`, and the number
  hooks (`__index__`, `__int__`, `__float__`, `__abs__`, `__round__` and the
  rest) that the builtins and `math` ask
- what packages use to look at code: a class's `__dict__` and `vars(cls)` are
  read-only views, `__mro_entries__` and `__orig_bases__`, a module's own
  `__getattr__`, `__spec__` on every module, and finders in `sys.meta_path`

`hash()` of a number or a tuple is CPython's, so `hash(2)` is 2 and
`hash(2.5)` is the same on the phone as on a computer.

`open` raises `PermissionError` and `input` raises `EOFError`, as there are
no files and no console to read. `%` formatting of bytes is not there.

**Modules you can import:**

| | |
|---|---|
| Built in | `math`, `random`, `time`, `json`, `re`, `sys` |
| Python's own | `abc`, `argparse`, `array`, `ast`, `asyncio`, `atexit`, `base64`, `binascii`, `bisect`, `builtins`, `calendar`, `cmath`, `codecs`, `collections`, `collections.abc`, `colorsys`, `concurrent.futures`, `configparser`, `contextlib`, `contextvars`, `copy`, `copyreg`, `csv`, `dataclasses`, `datetime`, `decimal`, `difflib`, `email` and its modules, `encodings.aliases`, `enum`, `errno`, `fcntl`, `fnmatch`, `fractions`, `functools`, `gc`, `getpass`, `gettext`, `glob`, `gzip`, `hashlib`, `heapq`, `hmac`, `html` with `html.entities` and `html.parser`, `http` with `http.client`, `http.cookies`, `http.cookiejar` and `http.server`, `importlib` (with `.util`, `.metadata`, `.resources`), `inspect`, `io`, `ipaddress`, `itertools`, `keyword`, `linecache`, `locale`, `logging`, `mimetypes`, `mmap`, `multiprocessing`, `ntpath`, `numbers`, `operator`, `optparse`, `os.path` (and `posixpath`), `pathlib`, `pickle`, `platform`, `pprint`, `queue`, `reprlib`, `secrets`, `select`, `selectors`, `shlex`, `shutil`, `signal`, `socket`, `socketserver`, `ssl`, `stat`, `statistics`, `string`, `struct`, `subprocess`, `sysconfig`, `tarfile`, `tempfile`, `textwrap`, `threading` and `_thread`, `timeit`, `token`, `tokenize`, `traceback`, `types`, `typing`, `unicodedata`, `unittest` and `unittest.mock`, `urllib.parse`, `uuid`, `warnings`, `weakref`, `webbrowser`, `xml.dom.minidom`, `xml.etree.ElementTree`, `xml.sax`, `xml.parsers.expat`, `zipfile`, `zlib`, `zoneinfo` |
| The keyboard's | `wm` and its modules on this page |
| Yours | every other `.py` file in your plugin: `import helpers` |

`time` has `time()`, `monotonic()`, `parts(seconds)` (a dict of `year`,
`month`, `day`, `hour`, `minute`, `second`, `weekday`, `yearday`) and
`format(pattern, seconds)` with Java date patterns such as
`"EEE d MMM yyyy"`, and Python's own `localtime`, `gmtime`, `strftime`,
`strptime`, `mktime`, `asctime`, `perf_counter` and `time_ns`. `sleep(0)`
returns, but a longer `sleep` raises `RuntimeError`, as the keyboard has to
keep answering keys: a plugin waits with `plugin.after(seconds, fn)`. `sys`
has `version_info` (3.13),
`platform` (`"android"`), `maxsize`, `argv`, `exit`, `getrecursionlimit`,
`setrecursionlimit`, `float_info`, `int_info`, `hash_info`,
`set_int_max_str_digits`, `getsizeof` (CPython's sizes), `flags` (none set),
`implementation` (named `"cpython"`), empty `prefix` and `base_prefix`, and
`modules` and `meta_path`, which imports read: a finder put in `meta_path`
supplies modules nothing else has, as with CPython's importlib.
`sys.stdout.write`, `print(..., file=sys.stderr)`,
`logging` and `warnings` all write to the plugin's log, where `print` goes.
`os` is only its path functions and an empty `environ`: files go through
[`wm.storage`](#storage) and [`wm.files`](#files).

Some modules stand in for what plugins go without, so packages that import
them still load:

- `threading`, `_thread` and `queue` have one thread. A lock is never held by
  anyone else, and a `Thread` runs its target when `start()` is called. What
  would wait for another thread raises `RuntimeError` instead of hanging: a
  blocking `acquire` of a held lock, or `wait()` with no timeout on an unset
  event or a condition. A `Timer` never fires.
- `pathlib` paths join, split and match as on Linux. Asking about the disk
  answers as for a path that is not there: `exists()` is false and `iterdir()`
  finds nothing. Reading or writing raises `PermissionError`.
- `subprocess` has its constants, exceptions and `CompletedProcess`. Starting
  a program raises `PermissionError`.
- `shutil` has `get_terminal_size` (80 by 24 unless `COLUMNS` and `LINES` in
  `os.environ` say otherwise), `copyfileobj` and `ignore_patterns`. Copying,
  moving and deleting files raise `PermissionError`, and `which` finds
  nothing.
- `platform` says Android on a 64-bit ARM phone, running the Python version
  `sys.version_info` gives. It leaves out who the phone is, so `node()` and
  `release()` are empty.
- `zoneinfo` knows only UTC and its aliases. A naive `datetime` is already in
  the phone's time zone.
- `gettext` finds no `.mo` files, so `translation(..., fallback=True)` gives
  the untranslated text; for your own plugin's languages use
  [`_()`](#translations). `locale` is the C locale.
- `xml.etree.ElementTree`, `xml.sax` and `xml.parsers.expat` read and write
  XML, with namespaces. The parser is written in Python, so it hands over a
  document once all of it has been fed in.
- `socket`, `ssl`, `select`, `selectors` and `socketserver` have their
  constants, exceptions and classes, and `socket`'s address helpers
  (`inet_aton`, `inet_pton`, `htons`) work. Opening a connection or asking
  the network anything raises `PermissionError`: web requests go through
  [`wm.http`](#http), or the keyboard's `requests` and `httpx`. `ssl`'s
  `SSLContext` keeps the settings it is given.
- `http.client` reads an HTTP response from any file object, and
  `http.cookies`, `http.cookiejar` and `http.server`'s request handlers work.
  Their connections and servers raise `PermissionError` when they would
  open a socket.
- `concurrent.futures` executors run each call when it is submitted and
  hand back a finished `Future`, so `map`, `as_completed` and `wait` work.
  `multiprocessing` has `cpu_count`, locks and queues, and a `Pool` that runs
  tasks in the plugin; starting a `Process` raises `PermissionError`.
- `tempfile.TemporaryFile` and `SpooledTemporaryFile` are held in memory.
  Anything that needs a name on disk raises `PermissionError`.
- `zipfile` and `tarfile` read and write archives in memory, such as in a
  `BytesIO` or a file from [`wm.files`](#files).
- `signal` keeps the handlers it is given, but no signal ever arrives.
  `glob` finds no files, `gc.collect()` frees nothing more, and `sysconfig`
  describes an empty installation. `getpass.getpass()` raises `EOFError`,
  `webbrowser.open()` answers `False`, and `mmap` and `fcntl` raise
  `PermissionError`.
- `atexit` keeps its functions, but a plugin never exits the way a program
  does, so nothing runs them. `linecache` has no lines to give.

`unicodedata` has normal
forms, categories, digit values and character names. Everything in
`itertools` hands out one item at a time, as in Python: `count`, `cycle` and
`repeat` go on without end, and `chain`, `groupby` and `tee` read their input
only as far as you take from them. `collections.Counter`, `defaultdict` and `OrderedDict` are dict
subclasses and `namedtuple` and `typing.NamedTuple` make tuple subclasses, as
in Python, so they go into `json.dumps` and pass `isinstance(x, dict)` or
`isinstance(p, tuple)`. `ChainMap`, `UserDict`, `UserList` and `UserString`
are CPython's. So is `functools`: `lru_cache` keeps the most recently used
calls (with `cache_info()`), and `partialmethod`, `singledispatch`,
`singledispatchmethod` and `cached_property` are there. `abc` marks methods
with `abstractmethod`, or the older `abstractproperty`,
`abstractclassmethod` and `abstractstaticmethod`, and a class that leaves
one unwritten can't be instantiated. In `enum`, an `IntEnum`, `StrEnum` or `IntFlag`
member, or one of `class Color(str, Enum)`, is a value of that type:
`Color.RED == "red"`, and `json.dumps` writes its value. `Flag` members
combine with `|`, `&`, `^` and `~`, and `Enum("Animal", "ANT BEE")` makes an
enum from names.

`asyncio` has no event loop. Awaiting a coroutine runs it to its end there and
then, so `create_task` starts one at once, `gather` awaits each in turn and
`sleep` returns without waiting; waiting on something only another task could
finish, such as an empty `Queue`, raises `RuntimeError`. `unittest` runs
`TestCase` classes with Python's assertion messages, and `unittest.mock` has
`Mock`, `MagicMock`, `AsyncMock`, `PropertyMock`, `patch` (with `.object`,
`.dict` and `.multiple`), `call`, `ANY`, `mock_open`, `create_autospec` and
`seal`. `zlib`, `gzip`, `struct`, `array`, `binascii` and `base64` work on bytes
in memory. `str.encode`, `bytes.decode` and `codecs` know UTF-8 (with or without
a signature), UTF-16, UTF-32, ASCII, Latin-1, Windows-1252, `unicode_escape`,
`rot13` and `hex`. `argparse` parses the list you give it; on bad input it
writes the usage to the log and raises `SystemExit`. `inspect` reads
signatures (the builtins' too, where CPython has one, such as `len` and
`sorted`) and kinds of object but has no source to show, `ast` has only
`literal_eval`, `importlib.import_module` imports by name, and
`importlib.metadata` finds no installed packages. A `weakref` keeps its object
alive, since there is no garbage collector to watch it go. `secrets` draws on
a seed taken once from the system's random source. `uuid` has `uuid1`,
`uuid3`, `uuid4` and `uuid5`; with no hardware address to read, `uuid1` uses
a random node, as CPython does when it finds none. `io.TextIOWrapper` reads
and writes text over a `BytesIO`.

`decimal`, `pickle`, `ipaddress`, `random`, `typing` and `tokenize` are
CPython's own modules, run as they are. `random` draws from CPython's Mersenne
Twister, so `random.seed(5)` gives the numbers CPython gives, and has
`Random`, `gauss` and the other distributions. `typing` is CPython 3.13's, with
the part CPython writes in C (`TypeVar`, `ParamSpec`, `TypeVarTuple`,
`Generic`, `TypeAliasType`) written in Python beside it; `typing_extensions`
and `attrs` run on it. A class's `__bases__` cannot be changed after it is
made, so a `NamedTuple` that is also `Generic` cannot be subscripted.
`decimal` is the pure-Python one CPython keeps beside its C
copy: exact and complete, but slower. A `Decimal` hashes like the int it
equals, though it is a different dict key from that int. `pickle` turns
values to bytes and back with `dumps` and `loads`, protocols 0 to 5, and
reads pickles CPython wrote; with no files, `dump` and `load` take a
`BytesIO`. `tokenize` is Python 3.11's tokenizer, the last one written in
Python, so an f-string comes out as one `STRING` token rather than 3.12's
`FSTRING_START` and the rest, and a `\r\n` line end comes out as `\n`.

The [classic reference](/plugins/api-reference/#the-python-you-get) has more
detail on the built-in modules, strings and dicts.

## plugin

`from wm import plugin`. The plugin itself.

### State

| | |
|---|---|
| `plugin.state(persist=False, key="state", **fields)` | An object holding `fields` with their starting values. Read and write them as attributes. With `persist=True` (needs `storage`), saved after every event and loaded again on the next open. Two saved states need different `key`s. |
| `state.update(**fields)` | Change several values. |
| `state.as_dict()` | The values as a dict. |
| `state.save()` | Save now instead of after the event. |
| `state["name"]`, `"name" in state` | Dict-style access. |

### Settings and context

| | |
|---|---|
| `plugin.settings.key` | The value of a manifest setting. `switch` gives `True`/`False`, `number` a number, `secret` the saved text or `None`, the rest text. An undeclared key raises `AttributeError`. |
| `plugin.settings.get(key, default=None)` | The same, with a default. |
| `plugin.settings.set(key, value)` | Change one of your settings; saved at once and shown on the page. A value that does not fit the row raises `ValueError`, a `host` setting `PermissionError`. |
| `plugin.settings.reset(key)` | Back to the manifest's default; a `secret` is forgotten. |
| `plugin.id`, `plugin.version` | From the manifest. |
| `plugin.permissions` | The declared permissions, as a tuple. |
| `plugin.locale` | The user's language, such as `"bn-BD"`. |
| `plugin.dark` | `True` in a dark theme. |
| `plugin.surface` | `"panel"` in the keyboard, `"float"` in the floating box, `"preview"` while showing a file. |

### Decorators

| | Called |
|---|---|
| `@plugin.on_open` | each time the panel opens, before the first draw |
| `@plugin.on_close` | when the panel closes |
| `@plugin.every(seconds=0, minutes=0, hours=0, name=None)` | again and again while the panel is open, at least one second apart |
| `@plugin.action(id)` | for the selection action `id` with the selected text; returns the replacement, or `None` |
| `@plugin.keyword(word)` | with the text after `@word` when the user presses your chip |
| `@plugin.provider(tool, id=None)` | when a provider list the user added you to asks; gets the request as a dict and returns the reply. [More](/plugins/guides/providers/) |
| `@plugin.preview(id)` | when the file manager shows a file the preview `id` reads; gets a [`PreviewFile`](#preview) and draws it with widgets. [More](/plugins/guides/file-previews/) |
| `@plugin.thumbnail(id)` | for the grid's picture of such a file; gets the same `PreviewFile` and returns PNG, JPEG or WebP bytes, or `None` |
| `@plugin.command(label, icon=None, id=None)` | when the user presses this button in the panel's header (three at most) |
| `@plugin.setting_changed(key)` | with the new value when the user changes that setting |

### Functions

| | |
|---|---|
| `plugin.after(seconds, fn, name=None)` | Call `fn` once, later, if the panel is still open. Returns the timer's name. |
| `plugin.cancel(name)` | Stop a timer. `True` if there was one. |
| `plugin.push(render_fn, title=None)` | Show another page; Back returns. |
| `plugin.back()` | Close the top page. `False` if there was none. |
| `plugin.set_title(text)` | The header text, instead of the plugin's name. |
| `plugin.close()` | Close the panel. |
| `plugin.open_settings()` | Open the plugin's page in Settings, where its settings are. Only in answer to something the user did in the panel. |
| `plugin.refresh()` | Draw again after this call. Events and timers already do. |

A function named `on_event(e)` gets every event no callback took, as a dict.

## ui

`from wm import ui`. Every widget can be used in a `with` block (containers)
or nested as arguments. [Drawing the panel](/plugins/guides/drawing/) explains
how.

Most widgets take `key=`, a stable id for when two widgets would look alike.

### Containers

| Widget | |
|---|---|
| `ui.column(*children, gap=None, align=None)` | top to bottom |
| `ui.row(*children, weights=None, gap=None, align=None)` | side by side. Buttons alone split the width evenly; beside a box or text they keep their own width and the rest share what is left. `weights=[2, 1]` sets the shares |
| `ui.grid(*children, columns=3)` | equal cells |
| `ui.card(*children, title=None, on_click=None, on_hold=None)` | a group; `on_click()`, and `on_hold()` on a long press |
| `ui.section(title, *children, collapsible=False, open=True)` | a titled part |
| `ui.scroll(*children, height=None)` | scrolls on its own |
| `ui.tabs(*pages, on_change=None)` with `ui.page(title, *children)` | `on_change(index)`; up to four tabs share the width, more scroll sideways |
| `ui.spacer(height=8)`, `ui.divider()` | |

### Text

| Widget | |
|---|---|
| `ui.label(text, style=None, color=None)`, `ui.text(...)` | a line of text |
| `ui.title(text)`, `ui.caption(text)` | big, and small |
| `ui.markdown(text)` | `#` headings, `-` bullets, `**bold**`, `*italic*`, `` `code` `` |
| `ui.output(text, mono=False, insertable=True, copyable=True)` | a result with **Insert** and **Copy** |

### Controls

| Widget | Callback gets |
|---|---|
| `ui.button(text, on_click=None, primary=False, enabled=True, icon=None, color=None, on_hold=None)` | nothing; `on_hold` hears a long press |
| `ui.icon_button(icon, on_click=None, label=None, enabled=True, on_hold=None)` | nothing |
| `ui.input(label=None, value=None, on_change=None, on_submit=None, placeholder=None, multiline=False, kind="text")` | the text; `kind` is `text`, `number`, `email`, `url` or `password` |
| `ui.search(placeholder=None, value=None, on_change=None, on_submit=None)` | the text |
| `ui.toggle(label, value=False, on_change=None)`, `ui.checkbox(...)` | `True`/`False` |
| `ui.slider(value, min=0, max=100, step=1, on_change=None, label=None)` | the number |
| `ui.stepper(value, min=None, max=None, step=1, on_change=None, label=None)` | the number |
| `ui.select(options, value=None, on_change=None, label=None, style="dropdown")` | the value; `style="segmented"` puts them side by side |
| `ui.chips(options, value=None, on_change=None, multi=False)` | the value, or a list with `multi` |
| `ui.date(label=None, value=None, time=False, step=15, on_change=None)` | seconds since 1970, or `None` |
| `ui.keys(rows, on_press=None)` | the key's label |

`options` is a list of values, or of `(value, label)` pairs.

### Lists

| Widget | |
|---|---|

## http

`from wm import http`. Needs the risky `network`, and the host in `hosts`.

| | |
|---|---|
| `http.get(url, params=None, **options)` | |
| `http.post(url, data=None, json=None, **options)` | also `put`, `patch` |
| `http.delete(url, **options)` | |
| `http.request(method, url, params=None, data=None, json=None, headers=None, timeout=15, binary=False, then=None, on_error=None, files=None)` | |

`data` is text, bytes, or a dict sent as a form. `json` is any value sent as
JSON. `files` sends a multipart upload form: `{"field": (name, bytes, type)}`,
`(name, bytes)`, plain bytes, or what `files.pick` and `files.photo` give,
with a `data` dict as its text fields. Your own `Content-Type` header wins
over the one the keyboard would pick. With `then=fn` the call returns at once
and `fn` gets the `Response`; `on_error=fn` gets any failure.

A `Response` has `status_code`, `ok`, `text`, `json()`, `content` (bytes),
`headers` (lowercase names), `url`, `reason` and `raise_for_status()`, which
raises `http.HTTPError` (an `OSError`, with `.response`) for 400 and up.

https only, 15 seconds, 1 MB, 60 requests a minute, nothing while Data saver
is on. Requests carry the User-Agent
`WMKeyboard-Plugin <id>/<pluginVersion> (+https://wmkeyboard.pages.dev)`. With the risky `network.local`, the server the user typed into a `host`
setting may also be on the local network, over http or https
([Permissions](/plugins/permissions/#networklocal)).
[Guide](/plugins/guides/internet-and-ai/).

## clock

`from wm import clock`. Needs `clock`. Rings in the keyboard's own Clock,
even with the keyboard closed. `clock.alarm(seconds, label=None)` sets a

## wm itself

`import wm` gives `wm.log(*values)` (a line in the plugin's log, like
`print`), `wm.timestamp(year, month, day, hour=12, minute=0, second=0)` (that
moment in the phone's time zone, in seconds since 1970),
`wm.zone_offset(zone=None, seconds=None)` (the UTC offset in seconds of a
time zone such as `"Asia/Tokyo"` at that moment, now by default, summer time
included; `None` is the phone's own zone; `ValueError` for a zone the keyboard
does not know), `wm.plugin_id`, `wm.plugin_version` and `wm.api_version`.

`zone_offset` is for showing a time where it happens: a train in Tokyo leaves
at Tokyo's 08:00 even when the phone is set to Dhaka.

```python
import wm

local = departure + wm.zone_offset("Asia/Tokyo", departure)
print(f"{local // 3600 % 24:02d}:{local // 60 % 60:02d}")
```

## Errors

Host calls raise ordinary Python exceptions:

| | |
|---|---|
| `PermissionError` | a permission is missing, not turned on, or the call is not allowed here |
| `ConnectionError` | no connection, Data saver on, or too many requests |
| `TimeoutError` | no answer in time |
| `http.HTTPError` | from `raise_for_status()` |
| `ValueError` | a bad argument, a colour that is not a role, storage over quota |
| `NotImplementedError` | a call this keyboard or the web preview does not answer |

With `then=`, every failure goes to `on_error` instead, if you gave one.
[Help](/plugins/help/#error-messages) lists the messages.

## Limits

| | |
|---|---|
| Archive | 64 files, 4 MB; scripts 256 KB each; assets 512 KB each |
| Widgets | 1,024 per draw, 128K characters of text |
| Storage | 512 keys, 64 KB a value, 1 MB in all |
| Network | 1 MB a reply, 15 seconds, 60 requests a minute, 16 hosts |
| Settings, actions, header buttons | 24, 16, 3 |
| Steps | 9M to load, 6M an event, 1.2M a draw, 9M a selection action |
| Time | 3 s to load, 2 s an event, 0.5 s a draw; waiting on the keyboard does not count |
| Lists, strings, recursion | 10,000 items, 100,000 characters, 300 calls deep |
| File previews | 20M steps and 5 s a preview, 3M and 1.5 s a thumbnail; 4,096 widgets and 1M characters; strings of 16M characters and lists of 200,000 items. [More](/plugins/guides/file-previews/#limits) |
