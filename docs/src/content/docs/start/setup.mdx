Installing WM Keyboard doesn't make it your keyboard. Android keeps every installed input method switched off until you enable it and then pick it as the active one. The app's Home screen has a card that walks you through both steps, and it disappears the moment you're done.

## Using the setup card

The card sits at the top of the app's Home screen until both steps are done, and it isn't a first-run-only banner: leave setup half finished and it's still there on the next launch. While it's on screen it checks Android's input-method state about once a second. There's no callback for "the user switched keyboards" while your app sits behind a system dialog, so polling is the only way to notice.

Both steps are always drawn, stacked, with only the one still to do live as a button:

1. **Not enabled.** The card reads "Turn on WM Keyboard in the system settings. Then select it as your keyboard." **Turn on keyboard** is the live button. **Switch keyboard** sits under it as a grayed-out outline, because there is nothing to switch to yet.
2. **Enabled, not selected.** The card reads "WM Keyboard is turned on. Press the button below to switch to it." **Turn on keyboard** now carries a checkmark and goes quiet. **Switch keyboard** becomes the live button.
3. **Enabled and selected.** The card goes away entirely. A green checkmark and "Your active keyboard" appear under the app name at the top of the Home screen instead. Nothing left to do.

Tap **Turn on keyboard** to open the system screen. Turn WM Keyboard's toggle on there. Tap **Switch keyboard** to open Android's "Change keyboard" sheet, which lists every enabled input method on the device. Tap WM Keyboard in that sheet to make it active. Both screens are also reachable through Android's own Settings app, if you'd rather not use the card at all.

The setup wizard's first page embeds the same card. There it stays put once you're done, as a short "WM Keyboard is your active keyboard" row with a checkmark in your app accent color.

## What the system permission warning means here

Enable any third-party keyboard and Android shows its own warning about keyboards being able to see everything you type. That text is the stock OS wording. WM Keyboard doesn't write it and can't customize it, and it reads a little differently on each Android version. The warning exists because *some* keyboards phone data home, which makes it worth knowing what this one does.

Core typing runs entirely on-device: the spelling dictionaries, transliteration, emoji search, prediction, everything you actually type with. All of it works with no network connection at all. A handful of optional toolbox features do reach the network, and only when you open them yourself. Weather, the word-definition lookup, translate, GIF and sticker search, web and image search, Wikipedia, and the AI writing tools pointed at a cloud provider each call their own service, and several want your own API key before they work at all. None of that runs in the background, and none of it runs while you're just typing. See [Privacy at a glance](/privacy/overview/) for the full breakdown.

## Running the setup wizard

The first time you open the app, it drops you into a short setup wizard instead of the Home screen. Every choice writes straight to settings as you make it. Going back, skipping ahead, or tapping **Skip** in the top corner therefore loses nothing, and you can change any of it again later.

There is no page for the app's own language. The app starts in your phone's language; to show it in a different one, use [About, App language](/reference/settings/about/#changing-the-apps-language).

The wizard tailors itself to a short quiz on its **Make it yours** page, so not everyone sees every step. "Keep it simple", or no answer at all, stops after the quiz (and Your languages, if you type in more than one). The full list:

<Steps>

1. **Welcome.** The setup card from above, embedded in the wizard. Enable and select WM Keyboard here and the wizard advances on its own. You do not have to tap Next after you come back from system settings. Under the card, **Restore a backup** takes a backup instead of the questions: see [Restoring a backup instead](#restoring-a-backup-instead).

2. **Make it yours.** Two quick questions, both optional: how many languages you type in, and whether you want a simple or a fully loaded keyboard. Each answer's subtitle spells out what picking it changes. Answers apply their defaults on the spot, and the rest of the wizard trims itself to match. Leave both alone and you get the short version. [What the quiz changes](#what-the-quiz-changes) below lists every setting each answer writes.

3. **Your languages** *(hidden if you answered "just one" language and only one is enabled)*. Your currently enabled languages come first, each with its layouts individually switchable, then a short **Suggested for you** list, then a search box for the other 840-odd. The suggestions come from your phone's own language settings and region. See [Suggested languages](/languages/overview/#suggested-languages) for exactly what's read. A language that ships one layout is added on the spot. A language that ships several (Bangla ships Avro, Probhat and National) opens a picker first, with its first layout already checked and a miniature of each key grid. Check as many as you want, but at least one.

4. **Look & feel** *(only for "show me everything" answers)*. Two controls only: theme mode (Auto/Light/Dark/AMOLED), then a grid of keyboard themes that match the mode you picked. Choose Auto and the grid splits into a Light tab and a Dark tab, so you pick one theme for each half.

5. **Typing feedback** *(skipped for "keep it simple" answers)*. Haptics, key sounds, and the key popup bubble.

6. **Spacebar & keys** *(skipped for "keep it simple" answers)*. One choice sets both spacebar-swipe directions, short and long, and a "Recommended" badge follows your quiz answer. There's also a toggle to replace the <KeyCap>🌐</KeyCap> key with an emoji key, and a number row toggle.

7. **Worth knowing about** *(only for "show me everything" answers)*. A tour of the features most keyboards don't have: smart chips, [per-app keyboards](/typing/modes/#keyboard-modes), tool hotwords, the toolbox, photo backgrounds, clipboard history and more. Most cards carry a switch right on them. The rest say where the feature lives. The per-app keyboards card sits second, and its switch is the master switch for [modes](/reference/settings/modes/). Modes are off until you turn them on: they're the one feature here that changes the keyboard without being asked, so setup offers the switch rather than springing it on you in the next app.

8. **Your tools** *(only for "show me everything" answers)*. Every toolbar tool, each with its own switch, plus quick "Recommended" and "Everything" buttons. Neither button, and no answer above, turns on Learn from text: that one stays off until you switch it on yourself.

9. **Tool setup** *(only for "show me everything" answers with Calendar, Weather, or Compass enabled)*. First-run choices for whichever of those you kept: alternate calendars and which days count as the weekend, a saved place (searched, typed, or read once from the phone) and a temperature unit, or a qibla toggle.

10. **Try your keyboard** *(skipped for "keep it simple" answers)*. A live text field, so the keyboard appears in the theme you picked. Up to three "try this" prompts come with it, drawn from what you enabled. Type `12*8=` for a smart chip, type `translate` for its hotword chip, or open the toolbox.

</Steps>

## Restoring a backup instead

Moving from another phone, or from another keyboard? **Restore a backup** on the Welcome page opens a file picker. It takes:

- a backup from WM Keyboard, `.wmconfig.json`, an encrypted `.wmconfig.enc` (it asks for the passphrase), or an older `.wmsettings.json`;
- a whole backup from HeliBoard, LeanType, FUTO Keyboard, FlorisBoard, CleverKeys or AnySoftKeyboard, where you pick what comes across first. See [Whole backups](/reference/importing-other-keyboards/#whole-backups).

If the file can't be opened, the dialog offers **Choose another file** instead of leaving you stuck. A backup can be up to 256 MiB here and on the Backup screen.

Once the backup is restored, the rest of the wizard is skipped: the quiz, the languages and every page after them. Your backup already answered all of it, and nothing the quiz would preset is written over it, the tool set included. Only the Welcome page is left, because no backup can turn a keyboard on for you. If WM Keyboard is already enabled and selected, the wizard closes by itself; if not, the page says so, and **Finish** stays open so you can do it later.

The languages in the backup get their word lists and prediction data downloaded in the background, the same way a language added on the wizard's own page does.

A file that is not a backup, such as a single theme or layout, imports as usual, and the wizard carries on.

## What the quiz changes

Each answer does two things: it writes a few settings there and then, and it decides which of the later pages you get. Here's the whole mapping, so you can see what you agreed to.

**How many languages do you type in?**

| Answer | What it writes | What it does to the wizard |
|---|---|---|
| Just one | Both spacebar swipes (short and long) move the cursor, and the <KeyCap>🌐</KeyCap> key stays an emoji key, which is what a fresh install ships | Your languages is skipped, unless you already have two or more enabled |
| Two or more | Both spacebar swipes change the language, and the emoji key next to the spacebar turns back into the <KeyCap>🌐</KeyCap> language key | Your languages appears |

Neither is a one-way door: the Spacebar & keys page later offers the same choice again, with a **Recommended** badge on whichever one matches your answer.

**What kind of keyboard do you want?**

| Answer | Toolbar tools it turns on | What it does to the wizard |
|---|---|---|
| Keep it simple | Eight: emoji, GIFs, stickers, clipboard, voice typing, AI writing tools, grammar check, and the settings shortcut | The short path. The wizard ends after the quiz |
| A good middle | 22: those eight plus themes, dictionary, fancy text, translate, autocorrect, snippets, one-handed, split, text editing, trackpad, handwriting, text scan, undo and redo | Adds Typing feedback, Spacebar & keys and Try your keyboard |
| Show me everything | 37: those 22 plus Wikipedia, vocabulary, power saving, keyboard modes, numpad, special symbols, calculator, unit converter, currency, password generator, calendar, weather, media controls, apps and hide keyboard | Also adds Look & feel, Worth knowing about and Your tools, and Tool setup when calendar, weather or compass is among them |

The same answer sets how much of the settings app shows until you pick for yourself: Simple, Standard or Everything. See [Choosing how many settings you see](/reference/settings/#choosing-how-many-settings-you-see).

A set that can't run in full on your phone gets topped up rather than left short. Part of it may be unavailable on your phone. Wikipedia and power saving then come in behind whatever's missing, so a "recommended" set never quietly arrives two tools smaller.

Leave the quiz alone entirely and you get the short page list, the same one "keep it simple" gets, plus the middle tool set when the wizard closes.

## Switching keyboards later

Once WM Keyboard is set up, there are a few ways to change which keyboard is active, or which of WM Keyboard's own languages is:

- **The Home screen's Switch keyboard button** comes back whenever WM Keyboard stops being the active keyboard, because the whole setup card returns with it. While WM Keyboard *is* active the card is gone, and the Home screen says "Your active keyboard" instead. Reach the picker from Android's own settings in that case.
- **The <KeyCap>🌐</KeyCap> key and spacebar swipes** cycle between WM Keyboard's *own* enabled languages. They don't open the system keyboard picker, so they can't switch you to a different keyboard app. A fresh install draws the emoji key in the <KeyCap>🌐</KeyCap> key's slot, so spacebar swipes are the language switch until you put the globe back.

The option below lists WM Keyboard's languages individually in Android's own switcher sheet, rather than as one generic "WM Keyboard" entry. It's off by default. Turn it on if you want to jump straight to one language from the system sheet.

## Options

<SettingsPath path="Languages & layouts / System language switcher" />

- **List languages in the Android switcher** (off by default). Registers each of your enabled layouts as an Android input-method subtype, so the system's "Choose input method" sheet lists them individually and can jump straight to one. Left off, the keyboard registers only one subtype, named after the keyboard and carrying the language you're typing in, so the sheet lists it under its own name while Android's spell checker still knows which language to check.
- **Show app name first** (off by default, and only shown while the option above is on). Prefixes each subtype's label with "WM Keyboard ·" instead of just the language name.
- **Select languages in the system settings** (also only shown while the first option is on). Opens Android's own subtype list. On Android 14 and newer the keyboard turns them on for you, so this is a repair tool. On Android 13 and older you have to turn them on here yourself, or the sheet shows only one.

<SettingsPath path="Privacy" />

- **Learn from typing** (on by default). Personalizes suggestions from what you type, entirely on-device.

See [Privacy at a glance](/privacy/overview/) and the [Privacy settings reference](/reference/settings/privacy/) for the rest of that screen.

## Running it again

The wizard isn't a one-shot. <SettingsPath path="About / Run setup again" /> replays it whenever you like. A replay presets nothing and seeds nothing, so walking through with Next writes no settings at all. It skips the Welcome page outright when the keyboard is already enabled and selected. Finishing a replay drops you back on the About screen.

## Details & edge cases

- Whether the wizard appears has nothing to do with whether the keyboard is enabled. A "have you finished onboarding" flag drives it, not a check of Android's input-method state. Enable and select WM Keyboard entirely from system Settings, without ever opening the app, and the wizard still appears on first launch. Its Welcome page just already shows the "done" state and lets you move straight past it.
- A restore from the Welcome page is the only way to skip the wizard that keeps the everything-enabled tool default when the backup has it. Skip and Finish otherwise replace it, as the next point says.
- Skipping the wizard early still lands a sane tool set. Finishing it, or skipping over the untouched everything-enabled default, replaces that default with the recommended set. Answer "keep it simple" first and you get the smaller essential set instead.
- On the F-Droid build the Tools page offers every tool. Handwriting, text scan and QR scanning read with open-source engines there, and the document scanner is the built-in one. See [Which build you have](/start/editions/).
- Installing over an existing WM Keyboard install (same signing key) keeps the wizard from running again. `onboardingDone` is a regular setting, so it carries over like any other. A clean reinstall, or a new phone with no settings backup, shows the wizard again. See [Installation](/start/installation/) for what does and doesn't carry over.
