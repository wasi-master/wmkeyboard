The Privacy screen is four groups, in this order: the way into the permissions inventory, learning on this device and incognito, Android's own backup opt-in, and the one button that clears learned data. Nothing else. This page is the field reference. For the reasoning and the rest of the privacy story, start at [Privacy at a glance](/privacy/overview/).

## Options

<SettingsPath path="Privacy" />

### Permissions

<SettingsPath path="Privacy / Permissions" />

| Setting | Control | Default |
|---|---|---|
| Permissions | Opens a sub-screen | n/a |

An unnamed group holding two navigation rows, sitting above everything else on the screen. The first is "See what the keyboard can reach, and give or take back a permission". It opens the permissions inventory, which is a screen of its own and has its own page here, [Permissions](/reference/settings/permissions/). Nothing on this row is a setting, so there's nothing to reset.

### Fingerprint lock

<SettingsPath path="Privacy / Fingerprint lock" />

| Setting | Control | Default |
|---|---|---|
| Fingerprint lock | Opens a sub-screen | Off |

The second row in the same group: "Ask for your fingerprint before the screens and the delete buttons that you pick". The right-hand side reads **On**, **Off**, or **Not available** when this phone has no fingerprint and no screen lock to check against.

It opens a screen of its own, where you turn the lock on and choose what it covers. Turning it on and turning it off both ask for a check. See [Fingerprint lock](/reference/settings/app-lock/) for the full field list.

Worth knowing before you turn it on: the lock hides screens inside the settings app, and it does not encrypt anything. An export file, the Android backup, USB debugging and a rooted phone all still reach the same data.

### Learning on this device

<SettingsPath path="Privacy / Learning on this device" />

| Setting | Control | Default |
|---|---|---|
| Learn from typing | Toggle | **On** |
| Add words to the system dictionary | Toggle | Off |
| Use the Android dictionary | Toggle | **On** |
| Expand Android dictionary shortcuts | Toggle | On |
| Incognito mode | Toggle | Off |
| Follow private browsing | Toggle | **On** |

**Learn from typing** is the master switch for the on-device word and word-pair lexicon. Turning it off stops new learning without deleting anything already learned.

**Add words to the system dictionary** also writes learned words to Android's own personal dictionary (System Settings → Languages & input → Dictionary), so other keyboards and the platform spell checker see them too. It's the one setting in this group that writes outside the app, which is why it defaults off even though the keyboard's own learning already covers the same ground.

**Use the Android dictionary** reads that same system dictionary the other way. Every word in it is a known word: it's suggested, autocorrect leaves it alone, and typing or gliding it never raises the "add to dictionary?" chip. The list is re-read whenever it changes, so a word added in System Settings works at once.

**Expand Android dictionary shortcuts** reads the shortcut column of that list. Type a shortcut you've defined there, say "omw", and it offers the full phrase, "on my way", as a suggestion.

**Incognito mode** and **Follow private browsing** are covered in full on [Incognito & secure fields](/privacy/incognito/), including exactly what pausing learning and clipboard capture means. Two things are worth knowing here. **Follow private browsing** defaults to **on**, the opposite of its neighbour "Incognito mode". And two related toggles, **Pause learning** and **Pause clipboard capture**, both on by default, live on <SettingsPath path="Tools / Incognito" /> rather than here. "Follow private browsing" appears on that Tools screen too. It's the same setting shown in both places, not a second copy.

### Android backup

<SettingsPath path="Privacy / Android backup" />

| Setting | Control | Default |
|---|---|---|
| Back up with Android | Toggle | Off |

**Back up with Android** folds the keyboard into Android's own backup and phone-to-phone transfer system. It's off by default, so nothing this keyboard stores is copied anywhere until you turn it on. Once on, it includes settings, themes, layouts, snippets, learned words, sticker and icon packs, plugins, imported fonts and the word lists you imported yourself, plus any saved API keys (Translate, AI tools, and the rest). Voice and AI models, downloaded dictionaries, and emoji-keyword packs are left out, because the keyboard can fetch them again on its own. So are four smaller things, all for size: the camera and document-scanner scratch folders, the images behind clipboard entries (the clipboard's text history stays), and the uncropped originals behind your stickers (the stickers themselves stay). A cloud backup is only made on devices that can encrypt it with your screen lock.

<PhoneFrame caption="The info dialog for Back up with Android, listing what's included and excluded.">
  {/* shot: reference/settings/privacy-backup-info-dialog */}
</PhoneFrame>

This is a different screen from the sibling **Backup & restore** item on the Settings home screen (route `backup`), which exports and imports a settings file by hand and never touches Google at all. See [Backup & restore](/privacy/backup/) for both paths side by side, and the [Backup & restore reference](/reference/settings/backup/) for that screen's own fields.

### Your data

<SettingsPath path="Privacy / Your data" />

A single row, **Learned words**, with a **Delete the learned words** button that asks to confirm first. Confirming deletes six files: your word and word-pair lexicon, the new words still waiting to be counted, your emoji-usage history, autocorrect's revert memory (which corrections you undid), your Chinese/Japanese/Cantonese pick history, and the language-mix tracker that remembers which language you tend to reach for. The dialog names the first four, warns that your personal dictionary goes with them, and promises that your snippets and your imported word lists stay.

Your personal dictionary really does go. The [Personal dictionary](/reference/settings/dictionaries/) screen edits the same word and word-pair lexicon file the keyboard learns into, so a word you added by hand and a word the keyboard picked up sit side by side, and this button takes both.

<PhoneFrame caption="Learned words, the only control in the Your data group.">
  {/* shot: reference/settings/privacy-clear-learned-words */}
</PhoneFrame>

This is the only bulk clear on this screen. Personal dictionary entries, clipboard history, and downloads each have their own per-item controls elsewhere. See [Your data on device](/privacy/data/#clearing-whats-stored) for the complete map of where every other category's clear control actually lives.

## Details & edge cases

- **"Delete the learned words" is one bulk action, not a per-category picker.** No dialog lets you choose which of the six files to wipe. Confirming deletes all six at once, with no undo.
- **"Follow private browsing" isn't two settings.** The row here and the row of the same name under <SettingsPath path="Tools / Incognito" /> both read and write `autoIncognito`; flip it in either place and the other reflects the change.
- **Saved API keys are included in an Android backup**, not excluded the way large downloads are. If that matters to you, use [Backup & restore](/privacy/backup/)'s manual export instead, which never leaves the device.
- **A cloud backup needs an encryptable screen lock.** On a device without one, turning "Back up with Android" on has nothing to actually back up into: Android's own backup system requires it.
- **The footer caption names the whole network side.** The screen's own note reads: "Typing works fully on this device. The word lists, prediction, autocorrect, transliteration and emoji search are part of the app, and none of them needs a network connection. The app collects nothing about you and has no analytics of its own. Handwriting, text scanning and QR scanning are built on Google's ML Kit, which reports its own diagnostics to Google while you use them. Only a tool uses the network, and only at the moment that you press it: translate, weather, web search, image search, GIFs, stickers, dictionary lookup and the AI tools. You can turn off each one of them on the Tools screen." See [Privacy at a glance](/privacy/overview/) for the same list with per-tool detail, plus the few fetches that happen without you pressing a tool.
- **No edition differences.** Every setting on this screen behaves the same on both the full and lite builds.
