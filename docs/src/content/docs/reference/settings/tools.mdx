The Tools screen is the enable switch and the settings entry point for all 64 of WM Keyboard's tools. Turn a tool on or off, tint its icon, or tap through to its own options. This page is the field reference for that one screen. For how the toolbar and toolbox actually work, including pinning, dragging, groups and direct boot, see [The toolbar](/tools/overview/) instead.

## The tool list

<SettingsPath path="Tools" />

Reach it from Home → **Tools**, or by searching "Tools" in settings search. A deep link also works: `wmkeyboard://settings/tools`.

A **Colorful tool icons** toggle sits above the list, on by default. It tints each tool's icon with its own accent colour, here and in the toolbox alike. Turn it off and every icon falls back to the theme's plain foreground colour.

Turning it on reveals **Gradient tool colors** underneath, off by default. On, each icon is painted with a two-colour gradient instead of one flat colour, running from its own colour at the top left to a second colour at the bottom right. The second colour is worked out from the first, so you get a gradient without picking anything. To choose both ends by hand, open the tool and set them there. The row is nested under the switch above rather than greyed out, because with the colours off there'd be nothing for a gradient to be made of.

Once you've recoloured at least one tool (either end of a gradient counts), a **Reset custom colors** button appears above the list and clears every per-tool override in one tap. It rides on the same switch: turn Colorful tool icons off and the button goes with the colours, overrides and all, until you turn them back on.

Below that, every tool gets one row: icon, name, a one-line description, an optional tune icon, and a switch. Tap the switch to enable or disable the tool. Tap anywhere else on the row to open that tool's own settings screen.

:::note[This screen doesn't control toolbar or toolbox placement]
Disabling a tool here removes it from the toolbar, the toolbox, and its hardware leader-key letter all at once, and that part is this screen's job. But *which* enabled tools are pinned to the toolbar itself, versus waiting in the toolbox, is a separate mechanism. You drag tools between the two on the keyboard's own toolbox. And the toolbar's display options live under <SettingsPath path="Appearance / Toolbar" />: height, spread vs. scroll, labels, grid size, and "Reset pinned tools". See [The toolbar](/tools/overview/) for all of that.
:::

### Groups

Tools are grouped by what they do, in this order:

| Group | Tools |
|---|---|
| Panels | Emoji, Clipboard, Snippets, Text editing, Trackpad, Numpad, Handwriting, Voice typing, Camera, Dictionary, Grammar check, App launcher |
| Scanners | Text scan (OCR), QR & barcode scanner, Document scanner |
| Online tools | Translate, GIFs, Stickers, Web search, Image search, Wikipedia, Currency converter, AI writing tools |
| Create and convert | Special symbols, Calculator, Unit converter, QR code generator, Password generator, Typing speed test |
| Keyboard modes | Keyboard modes, One-handed mode, Split keyboard, Floating keyboard, Resize |
| Cursor | The twelve one-tap cursor moves, Selection mode, plus Hide keyboard |
| Quick actions | Undo, Redo, Copy, Cut, Paste, Autocorrect, Fancy text, Custom layout, Incognito, Sound & haptics, Themes, Power saving, Settings shortcut |
| Utilities | Flashlight, Compass, Bubble level, Calendar, Weather, Moon phase |
| Other | Media controls, Plugins |

A tool that a future group forgets to claim still shows. It falls into the trailing **Other** catch-all, which is why Media controls and Plugins land there rather than in a group of their own. Nothing ever goes missing from the list.

A tune icon marks the tools with settings beyond the switch. Five are toggle-only here, because their real options live somewhere else: **Settings** (shortcut), **Themes**, **Sound & haptics**, **One-handed mode**, and **[Resize](/tools/resize/)**, whose values are all sliders under <SettingsPath path="Layout & size" /> anyway.

<Flavor edition="lite" /> hides the **Scanners** group entirely. Text scan, QR scan, and Document scanner are all unavailable, so the group has nothing left to show and doesn't render. **Panels** shrinks by two rows when Handwriting and Grammar check drop out, but it keeps its name and the rest of its tools. See [Lite edition](#lite-edition) below for the complete gating rule.

## Opening a tool's own screen

Every tool's detail screen, reached by tapping its row above, starts with the same three things, then adds whatever that specific tool needs:

1. **Turn on**: the identical switch from the list screen, just repeated here. Its subtitle reads "Show this tool on the toolbar and in the toolbox".
2. **Icon colour**: only shown while **Colorful tool icons** is on. Tap it to open the [colour picker](/themes/editor/#the-color-picker) for just this tool's icon. The swatch reads "Default" until you customise it, then "Custom." With **Gradient tool colors** on as well, this one row becomes two: **Icon colour, top left** and **Icon colour, bottom right**, one per end of the gradient. Leave the bottom-right one alone and it keeps tracking whatever you pick for the top left.
3. **Keyword shortcut**: a group, shown only for the tools that ship a built-in keyword. It holds a "Trigger words" field and a **Match capitals** switch, plus a "Reset to defaults" row once you've edited the words. Type one of a tool's words on its own (`wiki`, `calc`, `qr`, and so on) and a chip appears that opens the tool. [Smart chips](/smart/chips/#keyword-chips-open-a-tool) documents the feature in full. This screen only lets you edit or clear the words for one tool at a time.

## Managers built into a tool's screen

A handful of tools carry something bigger than a row of toggles: a model downloader, a list editor, a location picker. All of them live inline, inside that tool's own detail screen. None of them is a separate destination in Settings' navigation, apart from the three exceptions called out at the bottom of this table.

| Tool | What's there | Notes |
|---|---|---|
| Voice typing | Recognition engine choice, plus the Whisper model manager | Only appears <Flavor edition="full" />. Default engine is **System recognizer**; switching to **Offline Whisper** reveals a **Translate to English** toggle (off by default) and the model list. Full details: [Voice typing](/tools/voice/), [Offline voice (Whisper)](/tools/whisper/). |
| AI writing tools | Provider chips (Claude, OpenAI, Gemini, Grok, DeepSeek, Ollama, LM Studio, Other service, On your device) with per-provider API key or server fields, a local-model manager when On your device is selected, plus the action list, the changes view and the history | On your device is the only provider hidden on <Flavor edition="lite" />. See [AI tools](/tools/ai/). |
| Handwriting | A recognition-model manager, one entry per typed language | Each model is an on-demand ML Kit download of about 20&nbsp;MB. See [Handwriting](/tools/handwriting/). |
| Snippets | Full add/edit/delete list, plus import and export | Stored as a JSON file the tool manages itself. See [Snippets & text expansion](/tools/snippets/). |
| Weather | A location picker, plus a Fahrenheit toggle (off by default) | See [Instruments](/tools/instruments/). |
| Typing speed test | The default test's mode and length, its Punctuation and Numbers switches, a Typing aids group (Glide typing, Suggestions), a Records group (tests completed, recent average, best score per test length and language, and a "Clear records" row once there's something to clear), then an Achievements group | See [Utility tools](/tools/utilities/). |
| Plugins | A "Manage plugins" row | **This one opens a separate screen.** <SettingsPath path="Tools / Plugins" /> is just an entry point into [Plugins overview](/plugins/overview/), not an inline manager. |
| Stickers | A "Sticker packs" row alongside the tool's own settings | **Also a separate screen.** See [Stickers](/emoji/stickers/). |
| Media controls | A "Music players" row, plus a notification-access row that reports the grant | **Also a separate screen.** The picker lists every installed app, players first. See [Media controls](/tools/media/#which-apps-count-as-music). |

## Lite edition

<Flavor edition="lite" /> hides five tools completely. There's no settings row anywhere, not even a switch you can't turn on.

- Handwriting
- Text scan (OCR)
- QR & barcode scanner
- Document scanner
- Grammar check

Two more flags narrow what's *inside* a tool without removing the tool itself. The **On your device** AI provider chip and the whole **Offline Whisper** engine option are both full-only. AI writing tools and Voice typing still exist on lite, and still have a settings row, just with fewer choices on it. Lite ships 64 of the 69 tools.

One tool is gated by the device rather than the build. **Document scanner** is a Google Play services activity, so it's hidden on any phone without Play services, even on <Flavor edition="full" />. Text scan and QR scan stay, since their models are in the APK.

## Details & edge cases

- **Setup decides what starts enabled, not the shipped default.** The default really is all 69 tools on, but you only ever see it after a settings reset. The [setup wizard](/start/setup/) overwrites it the moment you answer its "how much keyboard do you want" question: 8 tools for "keep it simple", 21 for the middle answer, 35 for "show me everything", or all 69 if you tap **Everything** on its Tools page. Answering "extra strict" on privacy adds Incognito. A set that loses tools this build or device can't run (grammar, handwriting, the scanners) gets Wikipedia and Power saving in their place, so the exact count moves a little. The wizard only writes over an untouched default, so a reinstall with your settings intact keeps your selection.
- **Disabling a tool is one switch, not three.** The tool disappears from the toolbar, the toolbox, and its hardware leader-key letter at the same moment. You can't keep one of those and drop the others.
- **The tune icon is a hint, not a guarantee of depth.** Some tools with a tune icon add only one or two settings past the shared Turn on, Icon colour and Keyword shortcut rows. The icon means "there's at least one more setting," not "there's a lot here."
- **A tool's icon colour override survives disabling and re-enabling it.** Turning a tool off and back on doesn't reset any customisation made on its detail screen.
- **Build-gated tools leave no trace.** A tool hidden by the lite edition never appears as a disabled row: not in this list, not in settings search, not in the toolbox. The five lite-hidden tools are absent, and so is Document scanner on a device with no Play services.
- **Rows here get the same restore button as everywhere else.** Any switch or colour you've moved off its shipped value grows a small reset icon. See [putting one setting back](/reference/settings/#putting-one-setting-back) for how it behaves.
