The Appearance screen is where the keyboard's look comes together. It's the hub for the theme, font, and icon pickers, and it holds the sliders that shape the keys themselves and the toolbar above them.

## Style

<SettingsPath path="Appearance / Style" />

Three rows that each open their own screen rather than settings inline:

- **Keyboard themes**: light, dark, AMOLED, and custom colors, background images, and theme import/export. Shows the active theme's name, or "Default" when you haven't picked one. Full details on [Themes](/themes/overview/).
- **Keyboard font**: Google Fonts, or a font file you import yourself. Shows "System default" until you pick something else. Full details on [Fonts](/themes/fonts/).
- **Icons**: swap any tool or key icon individually, or install a whole icon pack. Shows "Default" with nothing changed, the active pack's name once one is installed, or a count of individually-changed icons. Full details on [Icon packs](/themes/icon-packs/).

Reference pages for each of these three screens: [Keyboard themes](/reference/settings/themes/), [Keyboard font](/reference/settings/fonts/), [Icons](/reference/settings/icons/).

## Keys

<SettingsPath path="Appearance / Keys" />

Three sliders that apply to every key, whatever layout is active. All three are the global value, and a theme may override any of them:

| Setting | Range | Default |
|---|---|---|
| Key corner radius | 0–28 dp | 8 dp |
| Key label font size | ×0.7–×2.0 | ×1.00 |
| Key hint font size | ×0.5–×3.0 | ×1.00 |
| Key hint position | −6–16 dp | 1 dp |
| Key hint side position | −6–16 dp | 0 dp |
| Key label across | −12–12 dp | 0 dp |
| Key label up or down | −12–12 dp | 0 dp |

**Key corner radius** goes from square keys at 0 to fully pill-shaped keys at 28. Turn on "Corner radii for this theme" in the theme editor and it seeds that theme's own key-radius slider from this value. See [Themes](/themes/overview/) for how a theme can override it.

**Key label font size** scales every printed letter on the keys themselves. It's separate from the popup bubble that appears on a key press, which has its own size under [Key press](/reference/settings/keypress/) → Key popup.

**Key hint font size** scales the small corner hint on a key: the character or symbol a long-press on that key types. This slider only controls their size once they're showing. The "Press and hold hints" toggle that turns the hints on or off in the first place lives on the [Key press](/reference/settings/keypress/) screen, not here. See [Key basics](/typing/basics/) for how long-press hints work.

**Key hint position** moves that corner hint up or down. At 0 the hint touches the top edge of the key. Raise it to bring the hint down toward the letter, or go below 0 to push it up into the key's own margin. **Key hint side position** does the same sideways: higher numbers move the hint in from the key's side, and below 0 moves it out to the edge.

**Key label across** and **Key label up or down** move the main letter on every key off its centre, so a corner hint made large enough to read, an Arabic haraka at ×2.5 for example, no longer sits under the letter. A layout can also make one key's hint larger than the rest with its **Hint size**, in the [layout editor](/languages/custom-layouts/).

## Toolbar

<SettingsPath path="Appearance / Toolbar" />

The toolbar is the strip above the keys that carries word suggestions while you type and your pinned tools otherwise.

<PhoneFrame side caption="The Toolbar group, with the confirmation dialog for turning the toolbar off.">
<Shot id="reference/settings/appearance-toolbar" alt="The Toolbar group, with the confirmation dialog for turning the toolbar off." />
</PhoneFrame>

| Setting | Type | Default | Notes |
|---|---|---|---|
| Show the toolbar | Toggle | On | Turning it off reclaims its height for the keys, but also hides suggestions and every pinned tool. You're asked to confirm before it disables. |
| Where the tools go | The strip / A button / Always | The strip | The strip is the original arrangement: tools and suggestions share one row and the arrow flips between them, so the tools are only in reach when nothing is being suggested. The other two give the tools a row of their own above the suggestions. A button opens and closes that row from the same arrow. Always leaves it open instead. Either way, having the row up costs one row's worth of keyboard height. Only shown while the toolbar is on. |
| Suggestion strip | Toggle | On | Keeps the suggestion row above the tools row. Turn it off to keep only the tools row and give the suggestion row's height back to the keys, for example if you've turned suggestions off and the row sits empty. It also removes everything else that appears in that row: the paste chip for your last copy, one-time codes, snippet offers and other chips. Voice typing's compact bar still takes the row while you dictate. Only shown while **Where the tools go** is set to Always, because with A button the arrow on the suggestion strip is how you open the tools. |
| Tools in landscape | Along the top / Left column / Right column | Along the top | With the phone on its side, takes the tools off the top of the keyboard and stands them in a column down the left or right edge, beside the suggestions and the keys, so they're always in reach. If **Where the tools go** gave them a row of their own, that row's height goes back to the keys. On the strip, the strip keeps only the suggestions and loses its arrow. The column follows the rest of the toolbar settings: your pinned tools and folders in their order, their colors and labels, the hold actions, **Rearrange by dragging** (drag up and down the column), and **Tool layout**, which spreads them down the column, packs them at the top, or lets them scroll. While a panel is open, the way back to the keys sits at the top of the column. A tool that takes the whole keyboard hides the column along with the rest of the bar, as does the toolbar-only view for a hardware keyboard. Portrait is unchanged. Only shown while the toolbar is on. |
| Swipe down to hide | Toggle | Off | A downward flick anywhere on the toolbar dismisses the keyboard. Only shown while the toolbar is on. |
| Press and hold delay | Slider, System or 100–1500 ms | System | How long you press a tool on the toolbar or in the toolbox before it counts as a hold: the hold action, the settings page, or picking the tool up. System follows the touch and hold delay in your phone's accessibility settings. Only shown while the toolbar is on. |
| Rearrange by dragging | Toggle | On | A press and hold that moves picks the tool up so it can be dropped elsewhere on the toolbar. Off, a hold that moves stays a hold, and the toolbox is where the bar gets rearranged. For anyone whose hold keeps turning into a drag. Only shown while the toolbar is on. |
| Only the toolbar with a hardware keyboard | Toggle | Off | With a physical keyboard attached, drops the on-screen keys and keeps just the toolbar strip. A keyboard button at the end of the toolbar brings the keys back when you want them. |
| Hide the keys when I type on the hardware keyboard | Toggle | On | Keys brought back with the toolbar's keyboard button go away again at the next key you type on the physical keyboard. Off, they stay until you tap the button. Only shown while **Only the toolbar with a hardware keyboard** and the toolbar are on. |
| Reverse the order for right-to-left languages | Toggle | Off | Mirrors the whole toolbar, toolbox button included, when the active layout's script runs right-to-left. The buttons beside the suggestions follow the same switch: off, they keep their side and order. Only shown while the toolbar is on. |
| Tool layout | Fixed size / Spread out / Scroll | Spread out | Fixed size packs the pinned tools to the left at one size. Spread out splits the width evenly. Scroll keeps each tool at a comfortable size and lets the bar scroll sideways; change the order from the toolbox while it is on. Only shown while the toolbar is on. |
| Toolbar top padding | Slider, 0–24 dp | 4 dp | Space between the top edge of the keyboard and the toolbar. The strip carries both suggestions and the toolbar, so the suggestions move with it, and the keyboard gets taller by the same amount. |
| Toolbar bottom padding | Slider, 0–24 dp | 0 dp | Space between the toolbar and the first row of keys. The keyboard gets taller by the same amount. |
| Hide the toolbar and the clipboard on the lock screen | Toggle | Off | Hides the whole top strip and blocks the clipboard panel while the phone is locked, so nothing like a copied one-time code sits on a screen anyone can wake. See [Tools](/tools/overview/#which-tools-work-before-you-unlock-your-phone) for how this differs from the tools that work before first unlock. |
| Tool labels | Toggle | Off | Draws a caption under each pinned tool's icon, the toolbox button at the head of the bar included (it reads **Toolbox**). Only shown while the toolbar is on. |
| Label text size | Slider, 7–14 sp | 10 sp | Only shown once Tool labels is on. |
| Keep labelled tools one width | Toggle | Off | Every labelled button keeps the tool width, and a longer name is cut short with an ellipsis instead of widening its button. Only shown once Tool labels is on. |
| Color the pinned tools | Toggle | Off | Gives the tools on the toolbar, and the buttons beside the suggestions, the colors they have in the toolbox, gradients included. Follows **Colorful tool icons**: with that off, there are no colors to give. Only shown while the toolbar is on. |
| Suggestion text size | Slider, 80%–160% | 100% | Scales the words in the suggestion strip without touching the strip's own height. |
| Suggestion spacing | Slider, 0–24 dp | 6 dp | The gap either side of each word inside its slot. Lower it to fit more of a long word before it shrinks, or to pack more words onto a narrow screen. Raise it to keep neighbouring words apart once [Scroll the suggestions](/reference/settings/typing/) is on. |
| Autocorrect word color | Color, or Auto | Auto | The color the strip paints its first suggestion in, but only once autocorrect has decided to put that word in for a space, so the color is a promise: a bold word without it is just the top guess, and a space keeps what you typed. Auto keeps the theme's text color. |
| New word color | Color, or Auto | Auto | The color the strip paints a word that no word list, your personal dictionary, your contacts or the spell checker knows. That is usually the word you are typing, so you can see it would be new to the dictionary before you add it from its hold menu or the keyboard learns it on its own; the color goes as soon as either happens. The autocorrect word color wins where both apply, and neither is used on a layout that turns your keys into another script, where the strip shows readings rather than the word as typed. Auto keeps the theme's text color. |
| Reset pinned tools | Button (confirms first) | n/a | Restores the global toolbar to Emoji, Clipboard, and Settings. It resets the global row even while a [mode](/typing/modes/) with its own pinned toolbar is active. To change what a mode pins, edit that mode instead. |
| Tool circle radius | Slider, 0–20 dp | 20 dp | 20 draws a full circle behind each tool icon, Gboard style. Smaller values give a rounded square. 0 removes the background, leaving bare icons. Has its own per-theme override in the [theme editor](/themes/editor/#corners). |
| Tool background shape | Row → picker dialog, the same twelve shapes as Key shape | Rounded | The outline of that background. Only Rounded and Cut read the radius above, and the rest size themselves off the button. Hidden while the radius is 0, since there is no background to shape. Has its own per-theme override in the [theme editor](/themes/editor/#toolbar-strip-and-popups). |
| Tool background width | Slider, 38–64 dp | 38 dp | How wide each tool's slot is once the bar stops spreading them, so it decides how many fit before the row scrolls or shrinks. Only shown while the toolbar is on. |
| Tool icon size | Slider, 14–30 dp | 22 dp | The icon inside each tool button, on the toolbar and in the toolbox grid. The button itself keeps its size, so the same number of tools fit either way. With Tool labels on, the icon draws 2 dp smaller (at most 26 dp) to leave room for the caption. |
| Reset toolbar *(shown only once something on this screen has moved)* | Button (confirms first) | n/a | Puts every slider and switch on this screen back to its default. Which tools are pinned is not affected. |

For the toolbox itself (pinning, reordering, and which tools work before you unlock your phone), see [Tools](/tools/overview/).

## Toolbox

<SettingsPath path="Appearance / Toolbox" />

The toolbox is the grid of every tool behind the toolbar's grid button. It is a different feature from the bar, so it has a page of its own.

| Setting | Type | Default | Notes |
|---|---|---|---|
| Reset toolbox order *(shown only once you've dragged the grid around)* | Button (confirms first) | n/a | Puts the tools in the toolbox grid back in their original order. The pinned bar is a separate list, reset by the row above. |
| Toolbox order | Your order / Most used / Recently used / A to Z | Your order | What puts the tools in order. Your order is the one you build by dragging. Most used puts the tools you open most often first, Recently used the one you opened last, A to Z sorts them by name. Tools never opened follow, in your order. The grid sorts itself as the toolbox opens, never while you tap in it, and a folder keeps its own order inside. |
| Toolbox layout | Icons / Pills | Icons | Icons is the round-icon grid with a caption under each tool. Pills gives every tool a wide rounded row instead: icon on the left, name beside it, and an arrow on the right for the tools that open something. |
| Toolbox grid size | Slider, 3–6 | 4 per row | Tools per row in the toolbox grid, the grid behind the toolbar's grid button. Fewer per row makes each tool bigger; more fits more tools without scrolling. Only shown while the layout is Icons. |
| Pills per row | Slider, 1–3 | 2 per row | How many pills sit side by side. Only shown while the layout is Pills. |
| Fill the pills with the tool color | Toggle | Off | Colors the whole pill with the tool's accent instead of just its icon, flipping the icon and name to whatever reads on top. Needs Colorful tool icons (under <SettingsPath path="Tools" />) to be on. Only shown while the layout is Pills. |
| Swipe the toolbox in pages | Toggle | Off | Breaks the toolbox into fixed pages you swipe sideways, with dots underneath, instead of one grid that scrolls. Applies to both layouts. |
| Tools per page | Slider, 4–40 | 12 per page | How many tools each page holds. Only shown once paging is on. |
| Toolbox label size | Slider, 0–16 sp (0 = follow the toolbar labels) | Follow toolbar | Sizes the captions in the toolbox on their own. At 0 the readout reads "Follow toolbar" and the captions take the toolbar's label size instead. |
| Space around each tool | Slider, 0–16 dp | 10 dp | The space above and below each tool and folder in the toolbox's icon grid. Less fits more rows on a page. The pill layout keeps its own spacing. |
| Toolbox search | Toggle | On | Shows a search button on the toolbar while the toolbox is open. The search opens over the whole keyboard with its own back button. Off leaves the toolbox with no search. |
| Search button at the far end | Toggle | On | Puts the toolbox search button at the far end of the toolbar, after the pinned tools, so a tap meant for back cannot open the search. Off moves it next to the back button. Only shown while Toolbox search is on. |
| Search order before typing | Your order / Most used / Recently used / A to Z | Your order | How the toolbox search lists every tool before you type anything. Once you type, the names that start with what you typed come first. Only shown while Toolbox search is on. |
| Reset toolbox *(shown only once something on this screen has moved)* | Button (confirms first) | n/a | Puts the grid layout, columns, paging, label size, the search button and its position, and both orders back to their defaults. The order of the tools, and which tools are switched on, are not affected. |

## Details & edge cases

- The **Keyboard themes**, **Keyboard font**, and **Icons** rows are shortcuts, not inline settings. Each opens its own full screen, so this page only covers what their trailing value means and where the real controls live.
- **Key label font size** and **key hint font size** are the global values, and a theme can override both. `ThemeSpec` carries its own nullable `fontScale`, `hintFontScale` and `boldKeyLabels`, so a theme that sets any of them wins over these sliders until you switch to one that doesn't. Key corner radius, tool circle radius, tool background width and tool background shape all work the same way. A theme can also set the toolbar's height, which has no global slider; the toolbar top and bottom padding add to it either way. A row the active theme's **Layout for this theme** group replaces says so under its name and greys out, so a slider that no longer reaches the keyboard is never mistaken for a broken one. The global value is kept and comes back the moment the theme stops setting it. See [Themes](/themes/overview/) for what a theme does and doesn't control.
- **Press and hold a tool** used to live here as its own screen. It moved onto each tool's own page under [Tools](/reference/settings/tools/), where the row is called **Press and hold on the toolbar**. See [Tools](/tools/overview/#hold-a-tool-for-a-second-action).
- Turning **Show the toolbar** off is the one *toggle* that asks you to confirm. Every other switch and slider here applies immediately, and turning the toolbar back on is instant with no confirmation. The reset buttons confirm too, since each one throws away an arrangement.
- **Tool layout** is one choice. Scroll used to be a second switch that silently overrode the spread one; the three options now say which layout you get.
- **Reset appearance** sits at the end of the Keys group and covers only the corner radius, the two label sizes and the hint position. The Toolbar and Toolbox pages each have their own reset.
- **Reset pinned tools** only touches the global toolbar row. A keyboard [mode](/typing/modes/) that carries its own pinned toolbar keeps it. You reset that from the mode's own editor instead.
