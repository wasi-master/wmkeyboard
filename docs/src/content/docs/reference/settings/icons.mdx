The Icons screen lists every glyph the keyboard draws, grouped by where it appears, with the active pack's controls above the list. This page walks the screen top to bottom. For why you'd swap icons and how to build a pack of your own, see [Icon packs](/themes/icon-packs/) instead.

## Options

<SettingsPath path="Appearance / Icons" />

Reach it from **Appearance → Style → Icons**, or by searching "Icons" in settings search.

### Icon pack

The first group lists **Built-in icons** (always the top row, selected whenever no pack is active), followed by one row per pack you've installed. Each installed row shows the pack's name, its icon count, and its author and version when the pack's manifest set them (for example "42 icons, by Jamie, version 1.2"). Tapping any row switches to it immediately.

Every installed row also carries two trailing buttons the built-in row doesn't have:

- **Export** opens a save dialog and writes that pack out as a `.wmicons` file, named after the pack. You'll see "The app saved `<pack name>`." on success, or "The app could not write that file." if the write fails.
- **Share with everyone** (the globe) sends the pack to the [community repository](/addons/community/). It is there on a row once the pack has at least one icon.
- **Delete** asks for confirmation first (a "Delete `<pack name>`?" dialog whose body reads "The app deletes its `<N>` icons from your device.") before removing the pack's files and any per-slot override pinned to it.

### Download, import and reset

Three rows sit below the pack list, in their own untitled group:

| Row | What it does |
|---|---|
| Download more | Opens the addon catalogue, already filtered to icon packs |
| Import an icon pack | Opens a file picker for a `.wmicons` file and installs it, switching to it right away. Several files, or a `.zip` of packs from **Export selected**, install every pack without switching, and one message counts them |
| Reset all icons | Turns off the active pack and clears every per-slot override in one step. Installed packs are kept: subtitle reads "This turns the pack off and deletes every single-icon change. The app keeps the installed packs." |

**Download more** sits first, next to the file importer, because the two answer the same question from opposite ends. One takes a `.wmicons` file you already have. The other goes looking for packs in whichever repositories you've added. See [Installing addons](/addons/installing/).

Unlike deleting a pack, Reset all icons runs immediately with no confirmation dialog. Afterward you see "Every icon is back to the built-in one."

### The slot list

Below that, the rest of the screen is the 111 replaceable slots, in four groups. Each group is a fold like the ones on the Tools screen: closed until you press its heading, naming what it holds while closed, and the screen remembers which ones you opened.

| Section | Covers | Slots |
|---|---|---|
| Tools | Every toolbar tool's own icon | 72 |
| Keys | Shift, Shift (on), Caps lock, backspace, forward delete, switch language, switch keyboard, emoji key, the four keys of the [arrow keys row](/reference/settings/layout/#arrow-keys-row), the plain <KeyCap>Enter</KeyCap>, and <KeyCap>Enter</KeyCap> in each of its six action wordings (search, send, go, next, previous, done) | 19 |
| Toolbar | Toolbox, back-to-keys, show-tools, emoji shortcut, close search, incognito badge, power saving badge | 7 |
| Emoji tabs | Search, recent, most used, and one per emoji category | 13 |

Each row's subtitle names where that icon currently comes from. You get the label of a built-in icon you picked by hand, the name of [another look](#other-looks) you picked for it, or "From `<pack name>`" if it's pulling from a pack (per-slot override or the active pack), or "Default" once nothing overrides it. The Tools rows use each tool's own settings-screen name, so a row here and that tool's own icon setting always agree on what it's called.

### Replacing one icon

Tapping any slot row opens its picker: a search field (placeholder "Search Material Symbols") over a grid of the 181 built-in icons, filtered live as you type. Tapping one sets that slot immediately and closes the dialog.

#### Other looks

Some slots have more than one drawing of the same idea, and for those the picker opens with an **Other looks** row above the search field: the slot's default look first, then each alternative, with its name underneath. Tapping one switches the slot to it and closes the dialog; tapping the default look puts the slot back, the same as **Use the default**. A slot with no alternatives has no row.

With the built-in icons, these slots have other looks:

| Slot | Other looks |
|---|---|
| GIF tool | **Letters** (the word GIF on its own, without the box), **Small letters** (the box's own letters, box removed) |
| Emoji tool, emoji key, emoji shortcut | **Simple** (a plainer smiley) |
| Clipboard tool | **Plain** (the clipboard without lines, the one Paste wears) |
| Settings tool | **Filled** |
| Voice tool | **Filled**, **Sound wave** |
| Web search tool | **Magnifier** |
| Appearance tool | **Brush** |
| Sound & haptics tool | **Speaker** |
| AI writing tools | **Robot** |
| Hide keyboard tool | **Arrow** (a downward chevron) |
| Incognito tool | **Hat and glasses** (the incognito badge's own glyph) |

When a pack is active and draws that slot, the row offers the pack's own alternatives instead, if it ships any, and hides when it ships none. A look you picked follows the pack you switch to: it shows the pack's drawing of that look when the pack has one, and the pack's ordinary icon for the slot when it doesn't. The row's subtitle on the slot list names the look while it's being drawn, for example "Letters".

Up to four tabs sit above the grid: **Built-in** (the Material Symbols grid and its search), **Your icons** (every picture you have added, with an **Add** cell first), **Packs** (only when an installed pack draws this slot) and **Installed** (only when the phone has a launcher icon pack such as Arcticons: a chip per pack, a search box, and the pack's icons; a one-colour icon follows the theme's colour). **Add** opens a file picker for SVG, PNG, WebP, JPEG and GIF, takes several files at once, adds each to Your icons and puts the first on the slot. A file that does not fit reports "The app cannot use these files: `<names>`. A file must be an SVG, PNG, WebP, JPEG or GIF smaller than 512 KB." With 200 pictures already stored it reports that Your icons is full. Touching and holding a picture opens its name, its colours (Automatic, Keep its own colours, Follow the theme) and Delete.

The dialog's confirm button reads **Use the default**, not "OK". It resets only the slot you're looking at, not the whole screen, and a picture from Your icons stays in the library. **Cancel** closes the dialog without changing anything.

**Your icons** on the Icons screen opens the whole library as a page, with **Export as an icon pack**, which saves every slot wearing one of your pictures as a `.wmicons` file. The pictures in the old reserved **My icons** pack move into Your icons the first time the keyboard or this screen opens after the update.

## Details & edge cases

- **Import limits.** The device holds at most 20 icon packs at once, and Your icons up to 200 pictures. Each SVG inside a pack is capped at 256 KB, and a `.wmicons` archive itself at 8 MB. Importing past the pack limit reports "You already have 20 icon packs. Delete one first." A file that isn't a recognizable icon pack reports "That file is not a WM Keyboard icon pack." One that can't be read reports "The app could not read that file."
- **Resolution order** for any slot is: a per-slot override you picked by hand, then the active pack (if it covers that slot), then the app's built-in default. Setting one icon from the picker always wins over an installed pack, even after that pack is later updated or swapped for another.
- **Deleting the active pack** turns off "active pack" entirely rather than only removing that row. Any slot that was relying on it, and wasn't separately overridden, falls back to the built-in icon.
- **Layout key glyphs aren't here.** The per-key symbols a language layout draws into its own keys are never part of this list, so an icon pack can't touch them. That covers the layout's keys, not the app's chrome. See [Icon packs](/themes/icon-packs/#what-you-can-replace) for why.
- **Colour follows the theme by default.** A row's icon that sets no colour of its own picks up the current theme's colour. With **Colorful tool icons** on, it picks up that tool's own accent colour too. See <SettingsPath path="Tools" />.
- **No build differences.** Everything on this screen behaves the same in every build.
