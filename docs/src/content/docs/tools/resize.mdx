**Resize** is the tool for the moment you think "this keyboard is a bit too short," without wanting to go digging through Settings for a slider. Tap it and the keyboard dims, an outline appears around it with a handle on each edge, and you drag until it looks right. Nothing is saved until you press **Done**.

## Turning it on

<SettingsPath path="Tools / Resize" />

Resize is one of the 72 toolbar tools, filed under **Keyboard modes** on the Tools screen next to Modes, One-handed, Split and Floating. Its row is just a switch: everything it changes already has a slider on the <SettingsPath path="Layout & size" /> screen, and the tool is only the in-place way to drag them.

You don't need the tool switched on to use resize mode once: **Resize by dragging** at the top of <SettingsPath path="Layout & size / Size and position" /> opens the test field with the keyboard already in resize mode.

Once it's on, it waits in the toolbox like any other tool, and you can drag it up onto the toolbar if you resize often enough to want it one tap away. See [The toolbar](/tools/overview/) for how pinning works.

## Dragging

Five things move:

- **The top handle** scales the keys. Both the key height and the number row height change together, keeping their ratio, so a taller keyboard doesn't leave the number row looking stranded. The bottom edge stays put.
- **The bottom handle** moves the bottom edge and leaves the top edge where it is. Drag it down and the keys grow into the gap below the keyboard; drag it up and the gap grows while the keys shrink. It stops when the gap runs out either way, so it can never lift the top edge.
- **The left and right handles** set the margin on that side of the keyboard, the same **Left padding** and **Right padding** values the Layout screen has as sliders. Each side is independent, so a right-handed thumb can shave the left edge alone.
- **The round move button** in the middle slides the whole keyboard up and down without changing its height, so you can lift it off the navigation bar with a thumb in the middle of the board rather than reaching for its edge.

While the tool is open the keyboard area on screen is held at the tallest the keyboard could reach, or the tallest window your phone will actually give the keyboard, so nothing moves under your finger mid-drag. Where that window is short, the held space shrinks to fit it rather than pushing the keys off the bottom of the screen. The app above doesn't move at all: it stays laid out where the keyboard's top edge was when you entered, dimmed behind that held space, and a keyboard you drag taller grows over it. The app catches up once, when you press Done.

Either side of the move button:

- **Reset** puts everything back to the values the tool opened with. It doesn't reset to the app's defaults, just to where you started this session, so a drag you regret costs you nothing.
- **Done** saves and leaves.

Below those, once the keys are narrower than the screen, sits a **Full-width toolbar** chip. Tap it and the toolbar and suggestion strip stretch back across the whole screen while the keys keep the width the side handles gave them, which is the tablet arrangement Samsung Keyboard uses. Tap it again to narrow them with the keys. Like the drags, it only previews until **Done**, and it saves to the same **Full-width toolbar** switch as the Layout screen, for the screen shape you're in.

Everything behind the outline is covered by a scrim that swallows every touch, so you cannot type by accident while you're dragging. Push a handle as far as it goes and it turns red and buzzes once, which is how you know you've hit the limit rather than lost the drag.

The limits are the same ones the sliders in Settings use: key height and number row height run from **32dp to 100dp**, the gap under the keyboard runs from **0dp to 160dp**, and each side margin runs from **0% to 30%** of the screen width.

## What gets saved, and where

Done writes to whichever screen shape you're currently in. In portrait, that's the plain **Key height**, **Bottom padding**, **Left padding** and **Right padding** values under <SettingsPath path="Layout & size / Size and position" />, plus the **Number row height** slider that sits one group higher under <SettingsPath path="Layout & size / Number row" />. In landscape, or unfolded, it writes that shape's own override instead, exactly as if you'd opened the per-screen group in Settings and moved the sliders there yourself. Resizing in landscape therefore never disturbs your portrait sizing. See [Size, position & one-handed use](/typing/size-position/) for how the per-screen overrides work.

Only the values you actually moved get written, and the **Full-width toolbar** chip counts as one of them only if you left it changed. Nudge the keyboard up without touching the top handle and no key height is saved at all, so a tablet still keeps its larger shipped default rather than being frozen at whatever number the drag happened to start from.

## Details & edge cases

- **Tapping the tool again cancels.** A second tap while resize mode is open closes it without saving, which is also what happens if you reach it twice from a hardware shortcut.
- **Done is the only thing that saves.** Anything else that takes the keyboard down drops the session unchanged: switching apps, hiding the keyboard, or the system **Back** gesture, which just dismisses the keyboard here. So does rotating, folding, unfolding, or moving to another display, since that swaps the screen shape out from under a preview that belongs to the old one.
- **It only works docked.** With the [floating keyboard](/typing/size-position/) on, the tool refuses and says "Dock the keyboard to resize it": floating has its own drag grip on the frame, and these handles are laid out against the docked shape.
- **One-handed mode switches off when you enter.** So does any open panel, which closes through the normal path rather than just vanishing, so nothing is left behind it.
- **It does nothing while the voice bar is up.** Finish or dismiss the dictation strip first.
- **It works before you unlock.** Resize is one of the 45 tools available during [direct boot](/tools/overview/#which-tools-work-before-you-unlock-your-phone), since it only touches the keyboard's own geometry.
- **A theme that pins its own key height wins afterwards.** Some themes ship a key height as part of their look. The drag previews fine and the value is saved, but the theme's number is what gets drawn once you're out of resize mode. A per-screen override beats the theme, so the same drag does stick in landscape or unfolded.
- **No hardware shortcut letter by default.** About two dozen tools have a default leader-key letter and Resize isn't one of them, but you can bind one under <SettingsPath path="Typing / Physical keyboard" />. See [Hardware keyboards](/typing/hardware-keyboard/).
- **The pill toolbox draws no arrow on it.** Resize doesn't open a panel or an activity, so it reads as an action rather than a destination, alongside Undo and Flashlight.
