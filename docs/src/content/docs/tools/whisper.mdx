---
title: "Offline voice (Whistle)"
description: "On-device speech recognition with Cactus Whistle."
---

Offline dictation uses **Cactus Whistle**, a compact speech-recognition model that runs locally through Cactus's Needle engine. After you download the model, speech audio stays on your device; this engine does not upload clips.

## Set it up

Open **Settings → Voice typing → Recognition engine**, choose **Offline Whistle**, then download the 16.9 MB model. The download is resumable and stored in the keyboard's private app storage. You can delete it from this screen or from **Storage → Voice models**.

The native runtime is included for ARM64 devices. On ARMv7 and x86_64 devices, and for unsupported languages, the offline-engine choice is hidden and Android's system recognizer remains available.

## Languages

Whistle currently transcribes **English, German, French, Spanish, Italian, Dutch, and Polish**. The layout language is passed to the model when it is one of those languages. For other languages, dictation uses Android's system recognizer instead; the former Whisper model catalog and its broader language coverage are no longer part of offline dictation.

Whistle transcribes a whole clip after recording stops, when you stop manually, when the 30-second capture limit is reached, or when the configured **Stop after a pause** interval elapses. The audio capture is 16 kHz mono and capped at 30 seconds. Silent clips are filtered before inference. Keyword biasing can use the entries in **Words to listen for**.

## Other recognition engines

The **System recognizer** remains available and can provide streaming partial results. Its supported languages and network behavior depend on Android and the recognition service installed on the device.

The **Transcription server** remains a separate option. It uploads a finished clip to the endpoint you configure, using the existing OpenAI-compatible audio-transcription API. Its server URL, key, model, and per-language configuration are independent of Whistle. See [Transcription server](/tools/transcription-server/) for setup details.

When a transcription server is selected while the device has no connection and **Use on-device models offline** is enabled, the keyboard uses Whistle for a supported language if its model is installed; otherwise it falls back to Android's recognizer.

## Privacy and attribution

Whistle inference runs locally after the model is downloaded. The one-time model download comes from [Cactus Compute on Hugging Face](https://huggingface.co/Cactus-Compute/whistle). The model and Needle engine are Apache-2.0; the engine's Android static libraries and upstream license notice are included in the source tree.
